# 검증 기록

## 로컬 환경

2026-10-12, Windows, Python 3.14, Chromium / Playwright 1.64.0.
검사 데이터는 자체 생성한 합성 메타데이터이며 실제 공격·악성코드·네트워크 접속을 실행하지 않았다.
단위·HTTP·공개 구성요소 테스트 67개: 66개 통과, Windows 심볼릭 링크 권한으로 1개 건너뜀.

## 기능 검증

- JSON·XML·UTF-16 XML 정규화 일치, 단일 Event, UTC·대소문자·GUID·경로 정규화.
- DTD·엔터티·외부 참조·중복 필드·잘못된 JSON·알 수 없는 라벨·구조 및 입력 한도 거부.
- 순서 독립성·중복 제외·PID 재사용·호스트 분리·부모 누락·시간 모순·순환 처리.
- 다섯 자체 규칙, 120/300초 경계, 사설·예약·멀티캐스트·인바운드·종료 후 연결 제외.
- 정확 일치 예외·제외 근거, 다른 명령은 제외하지 않음, 상세 한도에서 높은 위험 우선·전체 총계 보존.
- CLI JSON·배타적 생성·오류 코드·입력 경로 비노출, HTTP Host·Origin·본문·정적 경로 검증.
- 자산 체크섬·고지·합성 표본·런타임 의존성 공개 전 검사.

## 합성 시나리오 검증

18개 시나리오, 기본 TP 16 / FP 2 / FN 0, 조정 TP 16 / FP 0 / FN 0.
기본 17/18, 조정 18/18의 시나리오가 명시된 기대 결과와 일치한다.
이는 자체 합성 표본 회귀 검증이며 실환경 성능 측정·독립 평가 데이터 결과가 아니다.
TP/FP/FN 단위는 시나리오별 규칙 ID와 대상 이벤트 RecordID의 유일한 쌍이다.

## 브라우저 검증

1440px, 390px, 360px에서 다음 실제 UI 흐름을 확인했다.
파일 선택 -> XML 분석 -> 탐지 근거 -> 타임라인 -> 프로세스 트리 -> 규칙 비교 -> 예외 정책 -> 구간 재생·스텝·정지 -> JSON 저장.
검색·위험도 필터·110개 이벤트 페이지 이동·초기화·취소·HTML 파일명·bidi 제어 문자도 검증했다.
화면 캡처를 직접 확인했으며 페이지 가로 넘침·자산 누락·외부 요청·로그 HTML 실행·브라우저 오류가 없었다.
모바일의 긴 표와 탐색 메뉴는 해당 영역 안에서 가로 스크롤한다.

## 보안 및 검증 한계

Bandit 1.9.4의 `src` 분석 경고 0개. 정적 도구 결과는 취약점 부재 보장이 아니다.
Windows에서 심볼릭 링크 생성 권한이 없으면 관련 테스트 하나를 건너뛴다.
다른 OS/Python 및 원격 브라우저 결과는 GitHub Actions에서 별도로 검증한다.
실제 Sysmon 수집·설치, 실제 공격 실험, 침투 테스트, 상용 EDR 비교, 현장 오탐·탐지율, 법률 적합성은 검증하지 않았다.
